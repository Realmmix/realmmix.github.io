# Realm — Server Developer Portfolio

Personal portfolio site for **Realm** — professional Minecraft & Discord server development.
Static site, no frameworks. Designed to be hosted on **GitHub Pages**.

## Deploy to GitHub Pages

1. Create a repo (e.g. `realm.github.io` or any name).
2. Push this folder's contents to the repo root.
3. Repo **Settings → Pages** → Source: `main` branch, `/ (root)`.
4. Open `https://<username>.github.io/`.
